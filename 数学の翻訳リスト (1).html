4分野の全体像

数学の問題は大きく4つの分野に分かれます。問題文を読んだとき、まず「この問題はどの分野か」を特定することが③翻訳の出発点です。

🔢 代数（Algebra）
範囲数と式、方程式・不等式、整数、数列、場合の数・確率（計算系）
道具因数分解、展開、整数論（合同式）、漸化式、数学的帰納法
入試比重共通テスト：高。記述式：中〜高。整数は難関大で頻出
📐 幾何（Geometry）
範囲平面図形、空間図形、ベクトル、座標幾何、三角比・三角関数
道具三角比、余弦定理・正弦定理、ベクトル演算、座標計算、補助線
入試比重共通テスト：中〜高。ベクトルは記述式でほぼ必出
∫ 解析（Analysis）
範囲極限、微分、積分、関数の増減、面積・体積計算
道具微分法・積分法、増減表、絶対値の処理、置換・部分積分
入試比重理系入試で最重要。文系でも微積の基礎は必須
📊 統計・確率（Statistics）
範囲確率、確率分布、期待値・分散、統計的推測
道具加法定理・乗法定理、条件付き確率、二項分布、正規分布
入試比重共通テスト：高（統計分野が増加傾向）。記述式：中

各分野のメリット・デメリット

各分野には「得意にしたときのリターン」と「躓きやすいポイント」があります。自分がどの分野に時間を投じるべきかの判断材料にしてください。

🔢 代数

メリットデメリット・注意点
計算力があれば安定して得点できる。パターンが比較的明確で、暗記＋練習で伸びやすい 整数問題は発想力が必要で、難関大では差がつきやすい。数列の漸化式は式の変形ミスが多い
因数分解・展開は他分野の道具にもなる。代数が強いと全分野の計算処理が速くなる 「数式をこねくり回す」問題は試行錯誤が必要。方針が立たないと時間を大量消費する
共通テストでは数Ⅰの二次方程式・不等式など基礎問題の配点が大きく、コスパがよい 整数の証明は「ひらめき」に見えるが、翻訳の型（合同式・背理法・帰納法）を知っていれば対応可

📐 幾何

メリットデメリット・注意点
図を正確に描けるだけで解き方が見えることが多い。視覚的に理解できるので直感との相性がよい 補助線・補助点の発想が必要で、「どこに引くか」が分かるまでに時間がかかる
ベクトルは「方針さえ決まれば機械的に計算できる」分野。得意にすると安定した得点源になる 空間図形は3次元の把握が難しく、図を正確に描けないと詰まる。正射影ベクトルなど概念が難解
三角比（正弦定理・余弦定理）は暗記型で得点しやすい。共通テストでの出題比重が高い 座標幾何は計算量が多くなりがち。綺麗な数値が出ない問題は計算ミスのリスクが高い

∫ 解析

メリットデメリット・注意点
理系入試で配点が最も高い分野。微積を得意にすると入試で圧倒的有利になる 計算量が膨大。積分計算でのミス（符号・定数）が多く、時間を奪われやすい
増減表・グラフの概形など、視覚的な確認手段が豊富で自己チェックしやすい 「何を微分・積分するか」の方針判断が難しい問題がある。置換積分・部分積分の使い分けが課題
関数の最大・最小は微分の典型パターンで、翻訳が明確。練習すれば安定して解けるようになる 絶対値を含む積分・面積計算は場合分けが多く、吟味（⑦）を怠ると符号ミスで全滅する

📊 統計・確率

メリットデメリット・注意点
共通テストの「統計」分野は近年配点増加中。早めに対策するとコスパがよい 「同様に確からしい」の確認を怠ると根本的に間違える。前提の把握（①把握）が特に重要
確率は問題のパターンが比較的限られる（余事象・条件付き・反復試行など）。型を覚えれば安定する 条件付き確率（ベイズ）は直感と答えが逆になることが多い。実験（②）で具体例を作ることが必須
期待値・分散は公式を覚えれば機械的に計算できる分野。時間内に確実に得点できる 「独立な試行」と「従属な試行」の区別を間違えると全滅。前提の吟味（⑦）が特に重要

主要解法のメリット・デメリット

同じ問題に対して複数の解法が使えることがあります。どの解法を選ぶかは「自分の得意・時間・問題の形式」で判断してください。

因数分解
✅ メリット

式を簡単な積に変換できれば、解や等式変形が一気に進む。計算量が激減する

⚠️ デメリット・注意点

因数分解できない式に使おうとして時間を消費するリスクがある。できないと判断したら解の公式に切り替える判断力が必要

微分法（最大・最小）
✅ メリット

関数の最大値・最小値を求める最も汎用的な方法。増減表で視覚的に確認でき、ミスに気づきやすい

⚠️ デメリット・注意点

計算量が多い。端点の確認（閉区間での最大・最小）を忘れると失点する

相加相乗平均の不等式
✅ メリット

微分より計算が短い。正の数の和と積が与えられたときの最大・最小に威力を発揮する

⚠️ デメリット・注意点

等号成立条件の確認（⑦吟味）を必ず書く必要がある。忘れると減点。すべての変数が正であることの確認も必須

ベクトル
✅ メリット

空間図形の問題を「座標」を使わずに処理できる。内積を使えば角度・距離を機械的に計算できる

⚠️ デメリット・注意点

基底ベクトルの選び方を間違えると計算が複雑化する。問題によっては座標計算の方が速い場合もある

座標計算（解析幾何）
✅ メリット

直線・円の方程式を使えば、図形の問題を代数的に解ける。補助線の発想が不要になる

⚠️ デメリット・注意点

計算量が膨大になりやすく、文字が複雑になるとミスが増える。シンプルな図形ならベクトルや幾何的手法の方が速い

数学的帰納法
✅ メリット

「すべての自然数について成立する」という命題の証明に最も有効。手順が明確で書きやすい

⚠️ デメリット・注意点

\(n = k\) の仮定から \(n = k+1\) を示す変形が難しい問題がある。帰納法以外の証明（背理法・直接証明）も視野に入れる必要がある

積分法（面積・体積）
✅ メリット

面積・体積計算の唯一の手段。方針が明確で、定積分の計算さえ正確なら確実に得点できる

⚠️ デメリット・注意点

絶対値を含む場合・上下の曲線が入れ替わる場合の場合分けが複雑。計算量が多く時間がかかる

余事象・条件付き確率
✅ メリット

「〜でない確率」は余事象で計算する方が圧倒的に楽。条件付き確率は条件の絞り込みで計算量が減る

⚠️ デメリット・注意点

余事象を選ぶタイミングの判断が必要。「少なくとも1つ」という表現が余事象のサイン

翻訳リスト｜代数

問題文のキーワード使う解法・定理補足・注意点
整数 \(n\) が〇〇の倍数→\(n = k\)（整数）とおく合同式 \(n \equiv r \pmod{m}\) も有効
互いに素→最大公約数＝1。背理法で矛盾を導く\(\gcd(a, b) = 1\) を仮定して利用
自然数 \(n\) について証明せよ→数学的帰納法（\(n = 1\) で確認 → \(k\) で仮定 → \(k+1\) で示す）帰納法以外（直接証明・背理法）も視野に
整数解を求めよ→因数分解 or 合同式 or 不定方程式\(xy = c\)（積が定数）の形に変形して約数列挙
\(a + b + c\) が最小・最大（正の変数）→相加相乗平均の不等式等号成立条件 \(a = b = c\) の確認を忘れずに
数列 \(\{a_n\}\) の一般項を求めよ→漸化式を立てて特性方程式 or 変数変換等差型・等比型・\(a_{n+1} = p a_n + q\) 型を識別する
\(\sum\) の計算→公式（等差・等比・\(\sum k\)・\(\sum k^2\)）を適用部分分数分解・テレスコーピングも使う
余りが〇〇→合同式 \(a \equiv r \pmod{m}\)合同式のままで乗法・加法を適用できる
\(f(a) = 0\)→因数定理：\((x - a)\) で割り切れる有理数解を探すには \(\pm\)（定数項の約数）÷（最高次係数の約数）
2つの文字、方程式が2本→連立方程式（代入法 or 加減法）対称式の場合は \(s = x+y,\ p = xy\) とおく

翻訳リスト｜幾何

問題文のキーワード使う解法・定理補足・注意点
三角形の面積→\(S = \frac{1}{2}ab\sin C\)、または底辺×高さ÷22辺と挟む角が与えられたら前者一択
2辺と1角（SAS）が与えられている→余弦定理 \(c^2 = a^2 + b^2 - 2ab\cos C\)残り1辺を求めてから正弦定理へつなぐ
1辺と2角（ASA）が与えられている→正弦定理 \(\dfrac{a}{\sin A} = 2R\)外接円の半径 \(R\) を求める問題にも使う
点が直線上にある→ベクトル：\(\overrightarrow{AP} = t\overrightarrow{AB}\)（\(t\) は実数）内分点：\(t \in (0,1)\)、外分点：\(t \notin [0,1]\)
2直線が交わる（交点を求めよ）→ベクトル or 座標：連立方程式を解くベクトルで表現してパラメータ \(s, t\) を比較する
2つのベクトルが垂直→内積 \(\vec{a} \cdot \vec{b} = 0\)「垂直」→「内積＝0」は反射的に使えるようにする
2つのベクトルのなす角 \(\theta\)→\(\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}\)\(\theta \in [0°, 180°]\) に注意。鈍角になる場合もある
点と直線の距離→\(d = \dfrac{|ax_0 + by_0 + c|}{\sqrt{a^2+b^2}}\)直線を \(ax + by + c = 0\) の形に変形してから代入
円の接線→接点での半径⊥接線、または判別式\(D = 0\)外部の点から引く接線は2本あることに注意
重心・内心・外心・垂心→各点の定義に戻って座標またはベクトルで処理重心：\(G = \dfrac{A+B+C}{3}\)（位置ベクトルの平均）

翻訳リスト｜解析

問題文のキーワード使う解法・定理補足・注意点
最大値・最小値を求めよ（関数）→\(f'(x) = 0\) を解いて増減表 → 極値と端点を比較閉区間の場合は端点 \(f(a), f(b)\) の比較を忘れない
接線の方程式を求めよ→傾き \(= f'(a)\)、点 \((a, f(a))\) を通る直線\(y - f(a) = f'(a)(x - a)\)
単調増加・単調減少→\(f'(x) > 0\)（増加）、\(f'(x) < 0\)（減少）区間全体で符号を確認する
変曲点→\(f''(x) = 0\) かつ \(f''\) の符号が変わる点\(f''(a) = 0\) だけでは変曲点とは言えない（符号変化が必要）
2曲線の交点の間の面積→\(S = \int_{\alpha}^{\beta} |f(x) - g(x)|\,dx\)どちらが上側か確認してから絶対値を外す
体積を求めよ（回転体）→\(V = \pi \int_a^b \{f(x)\}^2\,dx\)\(x\) 軸回転か \(y\) 軸回転かを確認する
絶対値を含む積分→絶対値の中身が0になる点で積分区間を分割符号の確認（⑦吟味）を怠ると符号が逆になる
実数 \(k\) の範囲（グラフが交わる条件）→交点の個数 → 判別式 \(D \geq 0\) or グラフの位置関係3次方程式なら極大値・極小値の符号で個数を判断
等式の証明（関数）→差を取って \(h(x) = f(x) - g(x)\) とおき、\(h(x) \geq 0\) または \(= 0\) を示す微分して増減を調べ、最小値が0以上であることを示す
速さ・位置（物理的な設定）→速度 \(= \dfrac{dx}{dt}\)、位置 \(= \int v\,dt\)積分定数 \(C\) は初期条件から決定する

翻訳リスト｜統計・確率

問題文のキーワード使う解法・定理補足・注意点
少なくとも1つ〜→余事象：\(P(A) = 1 - P(\overline{A})\)「少なくとも1つ」は余事象のサイン。「1つも〜ない確率」を先に計算
AかつBの確率→乗法定理：\(P(A \cap B) = P(A) \cdot P(B|A)\)独立なら \(P(A \cap B) = P(A) \cdot P(B)\)
AまたはBの確率→加法定理：\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)排反なら \(P(A \cap B) = 0\) なので引く必要なし
〜が起きたときの〜の確率→条件付き確率：\(P(B|A) = \dfrac{P(A \cap B)}{P(A)}\)樹形図を書いてから計算すると分かりやすい
同じ試行を \(n\) 回繰り返す→反復試行：\(P = \binom{n}{k} p^k (1-p)^{n-k}\)二項分布 \(B(n, p)\) に従う
期待値を求めよ→\(E(X) = \sum x_i p_i\)（または二項分布なら \(E = np\)）確率の表を作ってから計算するのが確実
分散・標準偏差を求めよ→\(V(X) = E(X^2) - \{E(X)\}^2\)二項分布なら \(V = np(1-p)\)
\(n\) 個から \(r\) 個選ぶ（順序あり）→順列 \({}_n P_r = \dfrac{n!}{(n-r)!}\)順序が関係するかどうかを先に判断する
\(n\) 個から \(r\) 個選ぶ（順序なし）→組合せ \(\binom{n}{r} = \dfrac{n!}{r!(n-r)!}\)「選ぶ」「グループ分け」は組合せ。「並べる」「順番をつける」は順列
正規分布・標準化→\(Z = \dfrac{X - \mu}{\sigma}\) で標準正規分布 \(N(0,1)\) に変換正規分布表を読む問題では「以上・以下・間」の判断に注意

翻訳リスト｜分野横断キーワード

複数の分野をまたいで使われるキーワードです。これらが出てきたとき、どの分野の道具を使うかを問題全体の文脈から判断してください。

問題文のキーワード候補となる解法判断のポイント
最大値・最小値→ 微分法 / 相加相乗平均 / 二次関数の頂点 / 線形計画法 変数が1つ→微分。正の変数の和・積→相加相乗。整数制約→線形計画
2点間の距離→ 座標（距離の公式） / ベクトル（大きさ） 座標が与えられていれば距離公式。ベクトルで書かれていれば \(|\vec{AB}|\)
〜を \(n\) で割った余り→ 合同式 / 数学的帰納法 一般の \(n\) について証明するなら帰納法。具体的な \(n\) なら合同式
等式を証明せよ→ 変形して一致を示す / 差を取って0を示す / 帰納法 「差＝0」は微分で単調性を確認する方法が強力
不等式を証明せよ→ 差を取って符号確認 / 相加相乗平均 / 微分で最小値確認 差 \(f(x) - g(x)\) を定義して最小値が0以上であることを示す
関数 \(f(x)\) と実数 \(k\) が絡む→ \(k = f(x)\) とグラフの交点の個数で場合分け グラフを描いて視覚的に確認してから（②実験）式を立てる
整数 \(n\) を含む極限・無限→ 数列の極限 / はさみうちの原理 \(0 < r < 1\) なら \(r^n \to 0\) は即座に使える
条件を満たす点の軌跡→ 媒介変数消去 / 条件式から \(y = f(x)\) を導く 軌跡の問題は「点が存在する範囲」も吟味（⑦）が必要
