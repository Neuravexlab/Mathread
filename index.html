4分野の全体像

数学の問題は大きく4つの分野に分かれます。問題文を読んだとき、まず「この問題はどの分野か」を特定することが③翻訳の出発点です。

🔢 代数（Algebra）
範囲数と式、方程式・不等式、整数、数列、場合の数・確率（計算系）
道具因数分解、展開、整数論（合同式）、漸化式、数学的帰納法
入試比重共通テスト：高。記述式：中〜高。整数は難関大で頻出
📐 幾何（Geometry）
範囲平面図形、空間図形、ベクトル、座標幾何、三角比・三角関数
道具三角比、余弦定理・正弦定理、ベクトル演算、座標計算、補助線
入試比重共通テスト：中〜高。ベクトルは記述式でほぼ必出
∫ 解析（Analysis）
範囲極限、微分、積分、関数の増減、面積・体積計算
道具微分法・積分法、増減表、絶対値の処理、置換・部分積分
入試比重理系入試で最重要。文系でも微積の基礎は必須
📊 統計・確率（Statistics）
範囲確率、確率分布、期待値・分散、統計的推測
道具加法定理・乗法定理、条件付き確率、二項分布、正規分布
入試比重共通テスト：高（統計分野が増加傾向）。記述式：中

各分野のメリット・デメリット

各分野には「得意にしたときのリターン」と「躓きやすいポイント」があります。自分がどの分野に時間を投じるべきかの判断材料にしてください。

🔢 代数

メリットデメリット・注意点
計算力があれば安定して得点できる。パターンが比較的明確で、暗記＋練習で伸びやすい 整数問題は発想力が必要で、難関大では差がつきやすい。数列の漸化式は式の変形ミスが多い
因数分解・展開は他分野の道具にもなる。代数が強いと全分野の計算処理が速くなる 「数式をこねくり回す」問題は試行錯誤が必要。方針が立たないと時間を大量消費する
共通テストでは数Ⅰの二次方程式・不等式など基礎問題の配点が大きく、コスパがよい 整数の証明は「ひらめき」に見えるが、翻訳の型（合同式・背理法・帰納法）を知っていれば対応可

📐 幾何

メリットデメリット・注意点
図を正確に描けるだけで解き方が見えることが多い。視覚的に理解できるので直感との相性がよい 補助線・補助点の発想が必要で、「どこに引くか」が分かるまでに時間がかかる
ベクトルは「方針さえ決まれば機械的に計算できる」分野。得意にすると安定した得点源になる 空間図形は3次元の把握が難しく、図を正確に描けないと詰まる。正射影ベクトルなど概念が難解
三角比（正弦定理・余弦定理）は暗記型で得点しやすい。共通テストでの出題比重が高い 座標幾何は計算量が多くなりがち。綺麗な数値が出ない問題は計算ミスのリスクが高い

∫ 解析

メリットデメリット・注意点
理系入試で配点が最も高い分野。微積を得意にすると入試で圧倒的有利になる 計算量が膨大。積分計算でのミス（符号・定数）が多く、時間を奪われやすい
増減表・グラフの概形など、視覚的な確認手段が豊富で自己チェックしやすい 「何を微分・積分するか」の方針判断が難しい問題がある。置換積分・部分積分の使い分けが課題
関数の最大・最小は微分の典型パターンで、翻訳が明確。練習すれば安定して解けるようになる 絶対値を含む積分・面積計算は場合分けが多く、吟味（⑦）を怠ると符号ミスで全滅する

📊 統計・確率

メリットデメリット・注意点
共通テストの「統計」分野は近年配点増加中。早めに対策するとコスパがよい 「同様に確からしい」の確認を怠ると根本的に間違える。前提の把握（①把握）が特に重要
確率は問題のパターンが比較的限られる（余事象・条件付き・反復試行など）。型を覚えれば安定する 条件付き確率（ベイズ）は直感と答えが逆になることが多い。実験（②）で具体例を作ることが必須
期待値・分散は公式を覚えれば機械的に計算できる分野。時間内に確実に得点できる 「独立な試行」と「従属な試行」の区別を間違えると全滅。前提の吟味（⑦）が特に重要

主要解法のメリット・デメリット

同じ問題に対して複数の解法が使えることがあります。どの解法を選ぶかは「自分の得意・時間・問題の形式」で判断してください。

因数分解
✅ メリット

式を簡単な積に変換できれば、解や等式変形が一気に進む。計算量が激減する

⚠️ デメリット・注意点

因数分解できない式に使おうとして時間を消費するリスクがある。できないと判断したら解の公式に切り替える判断力が必要

微分法（最大・最小）
✅ メリット

関数の最大値・最小値を求める最も汎用的な方法。増減表で視覚的に確認でき、ミスに気づきやすい

⚠️ デメリット・注意点

計算量が多い。端点の確認（閉区間での最大・最小）を忘れると失点する

相加相乗平均の不等式
✅ メリット

微分より計算が短い。正の数の和と積が与えられたときの最大・最小に威力を発揮する

⚠️ デメリット・注意点

等号成立条件の確認（⑦吟味）を必ず書く必要がある。忘れると減点。すべての変数が正であることの確認も必須

ベクトル
✅ メリット

空間図形の問題を「座標」を使わずに処理できる。内積を使えば角度・距離を機械的に計算できる

⚠️ デメリット・注意点

基底ベクトルの選び方を間違えると計算が複雑化する。問題によっては座標計算の方が速い場合もある

座標計算（解析幾何）
✅ メリット

直線・円の方程式を使えば、図形の問題を代数的に解ける。補助線の発想が不要になる

⚠️ デメリット・注意点

計算量が膨大になりやすく、文字が複雑になるとミスが増える。シンプルな図形ならベクトルや幾何的手法の方が速い

数学的帰納法
✅ メリット

「すべての自然数について成立する」という命題の証明に最も有効。手順が明確で書きやすい

⚠️ デメリット・注意点

\(n = k\) の仮定から \(n = k+1\) を示す変形が難しい問題がある。帰納法以外の証明（背理法・直接証明）も視野に入れる必要がある

積分法（面積・体積）
✅ メリット

面積・体積計算の唯一の手段。方針が明確で、定積分の計算さえ正確なら確実に得点できる

⚠️ デメリット・注意点

絶対値を含む場合・上下の曲線が入れ替わる場合の場合分けが複雑。計算量が多く時間がかかる

余事象・条件付き確率
✅ メリット

「〜でない確率」は余事象で計算する方が圧倒的に楽。条件付き確率は条件の絞り込みで計算量が減る

⚠️ デメリット・注意点

余事象を選ぶタイミングの判断が必要。「少なくとも1つ」という表現が余事象のサイン

翻訳リスト｜代数

問題文のキーワード使う解法・定理補足・注意点
▶ 式・方程式・不等式
\(f(a) = 0\)→因数定理：\((x-a)\) で割り切れる有理数解候補：\(\pm\)（定数項の約数）\(\div\)（最高次係数の約数）
2つの文字、方程式が2本→連立方程式（代入法 or 加減法）対称式の場合は \(s=x+y,\ p=xy\) とおく
\(a+b+c\) が最小・最大（正の変数）→相加相乗平均の不等式等号成立条件 \(a=b=c\) の確認を忘れずに
▶ 数列
数列 \(\{a_n\}\) の一般項を求めよ→漸化式を立てて特性方程式 or 変数変換等差型・等比型・\(a_{n+1}=pa_n+q\) 型を識別する
漸化式 \(a_{n+1} = a_n + d\)（差が一定）→ 等差数列：\(a_n = a_1 + (n-1)d\) 「隣との差が定数」が見えたら即等差。\(a_{n+1}-a_n=d\) の形に整理して確認
漸化式 \(a_{n+1} = r \cdot a_n\)（比が一定）→ 等比数列：\(a_n = a_1 \cdot r^{n-1}\) 「隣との比が定数」が見えたら即等比。\(a_{n+1}/a_n=r\) の形に整理して確認
漸化式 \(a_{n+1} = a_n + f(n)\)（差が \(n\) の関数）→ 階差数列：\(a_n = a_1 + \sum_{k=1}^{n-1} f(k)\)（\(n \geq 2\)） \(b_n = a_{n+1} - a_n = f(n)\) とおいて \(\sum b_k\) を計算。\(n=1\) の確認を忘れない
漸化式 \(a_{n+1} = p a_n + q\)（\(p\neq 1,\ q\neq 0\)）→ 特性方程式 \(\alpha = p\alpha + q\) を解く → \(a_{n+1}-\alpha = p(a_n-\alpha)\) に変形 → 等比数列へ帰着 「定数をずらして等比にする」が基本戦略。\(\alpha\) を求めて \(b_n = a_n - \alpha\) とおく
漸化式 \(a_{n+1} = p a_n + f(n)\)（右辺に \(n\) の関数）→ 両辺を \(p^{n+1}\) で割る（または \(b_n = a_n / p^n\) とおく）→ 階差型に帰着 変数変換後の \(b_{n+1} - b_n\) が \(n\) の関数になれば階差で解ける
漸化式 \(a_{n+2} = p a_{n+1} + q a_n\)（3項間）→ 特性方程式 \(x^2 = px + q\) の2解を \(\alpha,\beta\) とする → \(a_{n+1}-\alpha a_n\) が等比に帰着 \(\alpha=\beta\) の重解の場合は \(b_n = a_n/\alpha^n\) とおいて等差型に帰着
漸化式 \(a_{n+1} = \dfrac{pa_n + q}{ra_n + s}\)（分数型）→ \(b_n = 1/a_n\) または \(b_n = (a_n - \alpha)/(a_n - \beta)\) とおいて等比型に帰着 「逆数をとる」「分離変数」が突破口。変換後に等比の形になるか確認する
\(\sum\) の計算→公式（等差・等比・\(\sum k\)・\(\sum k^2\)）を適用部分分数分解・テレスコーピングも使う
\(\dfrac{1}{k(k+1)}\) や \(\dfrac{1}{(2k-1)(2k+1)}\) の和→ 部分分数分解：\(\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}\) に分解 → テレスコーピング（隣の項が消える） 分解後に \(\sum\) を書き出すと「ほとんどが消えて端だけ残る」のが見える。消えずに残る項（最初と最後）だけ拾う
\(k \cdot r^k\)（等差×等比）の和→ 「ずらして引く」：\(S = \sum k r^k\) とおき、\(rS\) を作って \(S - rS\) を計算 → 等比数列の和に帰着 \(S - rS = (1-r)S\) の左辺は等比数列の和になる。\(r=1\) の場合は別途確認
等比数列の和 \(\sum r^k\) が途中で見える→ 等比数列の和：\(\displaystyle\sum_{k=0}^{n} r^k = \dfrac{1-r^{n+1}}{1-r}\)（\(r\neq 1\)） 分母に \((1-r)\) が出てきたら「等比の和の公式が使える」サイン。\(r=1\) は場合分けして \(n+1\) を代入
群数列（数列をグループに分けて考える）→ ① 第 \(n\) 群の末項番号を求める → ② 求めたい項が「第何群の第何項か」を特定する → ③ その項の値を一般式で表す 「第 \(n\) 群までの項数の総和」が末項番号になる。不等式 \(S_{n-1} < k \leq S_n\) で群を特定する
すべての自然数 \(n\) について証明せよ→数学的帰納法（\(n=1\) 確認 → \(n=k\) 仮定 → \(n=k+1\) を示す）帰納法以外（直接証明・背理法）も視野に
▶ 整数・余り・倍数
余りが〇〇 / 〇〇の倍数を示せ→合同式 \(a \equiv r \pmod{m}\)。周期性（べき乗の余りが繰り返す）に注目\(-1 \equiv m-1 \pmod{m}\) を使うと計算が楽になる場面が多い
約数・倍数が絡む→素因数分解 \(n=p^\alpha q^\beta\cdots\) → 約数の個数：\((\alpha+1)(\beta+1)\cdots\)約数問題は必ず素因数分解からスタート。大きい数はユークリッドの互除法
整数 \(n\) が〇〇の倍数→\(n=k\)（整数）とおく / 合同式 / 連続整数の積を作る連続する \(n\) 個の整数の積は \(n!\) の倍数。連続3整数の積は6の倍数
互いに素という条件→\(\gcd(a,b)=1\) に翻訳 → 背理法で「両方が素数 \(p\) の倍数」という矛盾\(\sqrt{2}\) が無理数の証明など、有理数・無理数の証明も同じ構造
最大公約数・最小公倍数（大きい数）→ユークリッドの互除法：\(\gcd(a,b)=\gcd(b,\ a \bmod b)\)\(\gcd(a,b)\cdot\text{lcm}(a,b)=a\cdot b\) と組み合わせる
整数解の組を求めよ（不定方程式）→積の形 \((x-a)(y-b)=c\) に変形 → \(c\) の約数を列挙して振り分け変形できない場合は特殊解を1つ探してユークリッドの互除法で一般解を作る
素数 \(p\) が登場する→積の形に分解 → 一方が必ず \(1\) に限定される。十分性の確認も必須「素数＝1と自分自身しか約数を持たない」を積の分解で使う
平方数 \(n^2\) が絡む証明・非存在→\(n^2 \bmod 3 \in \{0,1\}\)、\(n^2 \bmod 4 \in \{0,1\}\) という余りの制限を利用「このような余りにはなれない」と非存在を示す。モッド3・4・8で平方数の余りが限定される
存在を証明したい（鳩ノ巣原理）→余りで部屋を設計 → \(m+1\) 個の整数を \(\bmod m\) の \(m\) 部屋に入れれば必ず重複「どんな選び方でも存在する」の証明。部屋の設計が腕の見せどころ
ガウス記号 \(\lfloor x \rfloor\)→\(\lfloor x \rfloor = n \Leftrightarrow n \leq x < n+1\) に翻訳階乗に含まれる素数 \(p\) の個数：\(\sum_{k \geq 1} \lfloor N/p^k \rfloor\)
▶ 解と係数の関係
2次方程式の2解 \(\alpha,\beta\) の和・積・差→\(\alpha+\beta=-b/a\)、\(\alpha\beta=c/a\)、\(|\alpha-\beta|^2=(\alpha+\beta)^2-4\alpha\beta\)解を直接求めず、和・積だけで答えられる問題が多い。対称式は和・積に帰着
直線（または \(x\) 軸）が切り取る弦の長さ→ 交点の2 \(x\) 座標を \(\alpha,\beta\) とおく → \(|\beta-\alpha|^2=(\alpha+\beta)^2-4\alpha\beta\) に代入 解そのものを求めなくていい。和・積を係数からすぐ読み取れるので圧倒的に速い。「解を求めてから引く」と思い込んでいる人が多いが、\(\beta-\alpha\) が出てきた瞬間に解と係数の関係を使うサイン
3次方程式の3解 \(\alpha,\beta,\gamma\)→\(\alpha+\beta+\gamma=-b/a\)、\(\alpha\beta+\beta\gamma+\gamma\alpha=c/a\)、\(\alpha\beta\gamma=-d/a\)1解が分かれば残りは2次方程式に帰着できる
「2解がともに整数」→和・積が整数 → 大きい方を設定して範囲を絞る → 積の約数を列挙判別式より解と係数の関係から列挙する方が速い場面が多い
「2解の符号が逆」（異符号の解）→積 \(\alpha\beta < 0\) → \(c/a < 0\) に翻訳判別式を使わなくても符号条件だけで絞れる
2解を新しい解とする方程式を作れ→新しい解の和・積を計算 → \(t^2-(\text{和})t+(\text{積})=0\) に代入例：新しい解が \(\alpha^2,\beta^2\) なら \(\alpha^2+\beta^2=(\alpha+\beta)^2-2\alpha\beta\) で計算
対称式 \(\alpha^2+\beta^2\)、\(\alpha^3+\beta^3\) などを求めよ→基本対称式（和・積）に帰着：\(\alpha^2+\beta^2=(\alpha+\beta)^2-2\alpha\beta\)すべての対称式は「和」と「積」の式で表せる（対称式の基本定理）
複素数解を持つ（係数が実数の方程式）→虚数解は共役ペア → 和が \(2\,\text{Re}(\alpha)\)、積が \(|\alpha|^2\)（ともに実数）解と係数の関係で実部・虚部を係数から特定する

翻訳リスト｜幾何

問題文のキーワード使う解法・定理補足・注意点
▶ 三角比・三角形
三角形の面積→\(S=\frac{1}{2}ab\sin C\)、または底辺×高さ÷22辺と挟む角が与えられたら前者一択
2辺と1角（SAS）が与えられている→余弦定理 \(c^2=a^2+b^2-2ab\cos C\)残り1辺を求めてから正弦定理へつなぐ
1辺と2角（ASA）が与えられている→正弦定理 \(\dfrac{a}{\sin A}=2R\)外接円の半径 \(R\) を求める問題にも使う
▶ ベクトル・座標
点が直線上にある→ベクトル：\(\overrightarrow{AP}=t\overrightarrow{AB}\)（\(t\) は実数）内分点：\(t \in (0,1)\)、外分点：\(t \notin [0,1]\)
2直線が交わる（交点を求めよ）→ベクトル or 座標：連立方程式を解くベクトルでパラメータ \(s,t\) を比較する
2つのベクトルが垂直→内積 \(\vec{a}\cdot\vec{b}=0\)「垂直」→「内積＝0」は反射的に使えるようにする
2つのベクトルのなす角 \(\theta\)→\(\cos\theta=\dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}\)\(\theta \in [0°,180°]\) に注意。鈍角になる場合もある
点と直線の距離→\(d=\dfrac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}\)直線を \(ax+by+c=0\) の形に変形してから代入
円の接線→接点での半径⊥接線、または判別式 \(D=0\)外部の点から引く接線は2本あることに注意
重心・内心・外心・垂心→各点の定義に戻って座標またはベクトルで処理重心：\(G=\dfrac{A+B+C}{3}\)（位置ベクトルの平均）
▶ 複素数平面
複素数 \(z\) が実数 / 純虚数→実数 \(\Leftrightarrow z=\bar{z}\)。純虚数 \(\Leftrightarrow z=-\bar{z}\)（かつ \(z\neq 0\)）\(z=a+bi\) とおいて虚部 \(b=0\)（実数）または実部 \(a=0\)（純虚数）に翻訳
分母に複素数がある / \(|z|\) を実数化したい→共役 \(\bar{z}\) を掛けて実数化：\(z\bar{z}=|z|^2\)\(z+\bar{z}=2\,\text{Re}(z)\)、\(z-\bar{z}=2i\,\text{Im}(z)\) もセットで覚える
